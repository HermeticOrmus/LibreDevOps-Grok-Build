# Security

Report vulnerabilities privately to the HermeticOrmus maintainers (see org profile / funding contacts).

Do not file public issues with exploit details.

This suite is documentation and prompts for DevOps / IaC / CI — not a network service. Still: never embed secrets in skills, templates, or examples. Never print secret values in issues, PRs, or chat.

Hardening and review only. Skills in this pack must not ship exploit steps, payloads, or attack scripts.

See also [GOLD_HAT.md](./GOLD_HAT.md).
