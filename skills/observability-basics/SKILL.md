# Observability Basics

See the system without drowning in noise.

## Steps
1. Define SLIs/SLOs for the user job.
2. Structured logs with correlation IDs.
3. Golden metrics (latency, errors, saturation).
4. Trace critical paths.
5. Alert on symptoms, not just causes.
